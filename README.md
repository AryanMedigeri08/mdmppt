# H-Computing in Data Science — 16:9 Interactive Presentation Project

## Project Folder Structure
- `index.html` — Self-contained 16:9 full-screen interactive presentation deck
- `css/style.css` — Custom widescreen scaling & auditorium typography stylesheet
- `js/slides-data.json` — Structured slide notes, transitions, and verified citations
- `assets/logos/` — Vector brand logos (NVIDIA, AMD, HPE, AWS)

## Controls & Navigation
- **Left / Right Screen Click**: Click anywhere on the right half of the screen for Next Slide, or the left half for Previous Slide.
- **Bottom-Left Circular Button**: Click to expand or collapse the control bar (Slide Number, Notes & Sources, Grid Overview, Full Screen, Nano Banana AI Generator, and ZIP Export).
- **Keyboard Shortcuts**: `ArrowRight` / `Space` (Next), `ArrowLeft` (Previous), `N` (Speaker Notes), `G` (Grid Overview), `F` (Full Screen).
